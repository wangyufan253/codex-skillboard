# 开发测试

普通使用者按 README 启动产品服务即可。以下入口用于维护者的自动化验证。

## 自动化测试

运行 `npm test`，需要 Node.js 24+ 和 PATH 中的 Codex CLI。配置写入、安装与卸载等集成测试使用临时 `CODEX_HOME` 和临时用户目录，不修改使用者的配置，不调用模型。

## 浏览器回归

运行 `npm run test:ui:serve` 后按终端输出地址打开测试页。该页面会执行 `test/browser-scenarios.js` 中的交互检查，修改并重置临时测试数据；它不是产品演示地址，也不是用户真实聊天。

服务默认使用独立测试端口，结果从同一服务的 `/ui-test-result` 读取。验证结束后关闭测试进程。页面截图和日志应存放在临时目录，避免将真实项目、聊天、个人路径或凭据提交到仓库。
